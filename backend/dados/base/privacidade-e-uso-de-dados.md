# Privacidade e Uso de Dados

## O que coletamos

Dados de cadastro, historico de pedidos e dados de navegacao no site. Dados de
pagamento sao processados pelo provedor de pagamento e nao ficam armazenados
por nos.

## Para que usamos

Processar o pedido, emitir nota fiscal, entregar, atender e cumprir obrigacoes
legais. Uso para comunicacao promocional depende do seu consentimento e pode
ser revogado.

## Por quanto tempo

Dados fiscais sao mantidos pelo prazo legal de **5 anos**. Dados de cadastro
sao mantidos enquanto a conta existir.

## Seus direitos

Acesso, correcao, portabilidade e exclusao dos dados, conforme a LGPD. A
solicitacao e feita pelo canal de atendimento.

## Compartilhamento

Compartilhamos com transportadora e provedor de pagamento apenas o necessario
para a entrega e para a cobranca.
