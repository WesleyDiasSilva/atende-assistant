# Privacidade e Uso de Dados

## O que coletamos

Dados de cadastro, histórico de pedidos e dados de navegação no site. Dados de
pagamento são processados pelo provedor de pagamento e não ficam armazenados
por nós.

## Para que usamos

Processar o pedido, emitir nota fiscal, entregar, atender e cumprir obrigações
legais. Uso para comunicação promocional depende do seu consentimento e pode
ser revogado.

## Por quanto tempo

Dados fiscais são mantidos pelo prazo legal de **5 anos**. Dados de cadastro
são mantidos enquanto a conta existir.

## Seus direitos

Acesso, correção, portabilidade e exclusão dos dados, conforme a LGPD. A
solicitação é feita pelo canal de atendimento.

## Compartilhamento

Compartilhamos com transportadora e provedor de pagamento apenas o necessário
para a entrega e para a cobrança.
